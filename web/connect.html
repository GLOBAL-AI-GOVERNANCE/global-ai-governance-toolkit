For AI agents

Connect your agent

Read first: llms.txt and machine-interface.json list the CLI, inputs, outputs, profiles, and raw schema URLs.

Use it in your agent in 5 minutes with gag-mcp, a read-only MCP server with three tools: check_inventory, build_decision_pack, and validate_passport.

git clone https://github.com/GLOBAL-AI-GOVERNANCE/gag-mcp && cd gag-mcp
python3 -m venv .venv && . .venv/bin/activate && pip install -e .
./scripts/fetch_upstreams.sh
gag-mcp                      # stdio (Claude Desktop and other local clients)
gag-mcp --http --port 8000   # Streamable HTTP at /mcp

Claude: add "gag": {"command": "/ABS/PATH/gag-mcp/.venv/bin/gag-mcp"} under mcpServers, or add a custom connector at https://YOUR-HOST/mcp.
ChatGPT / OpenAI API: tool {"type": "mcp", "server_label": "gag", "server_url": "https://YOUR-HOST/mcp"}.
Grok / xAI API: tool {"type": "mcp", "server_label": "gag", "server_url": "https://YOUR-HOST/mcp"}.

Remote platforms need a public HTTPS endpoint. A hosted Global AI Governance endpoint is not yet available; self-host with gag-mcp --http.
