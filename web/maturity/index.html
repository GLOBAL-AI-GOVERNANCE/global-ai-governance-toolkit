Maturity is a judgment a person makes and stands behind. This local page checks whether the submitted evidence can carry that rating. It does not score maturity, certify, or authorize deployment.

Advisory vs enforcement. Browser and CLI maturity results are advisory. Runtime enforcement is the MCP guard and hooks, not this page.

Assessment setup

Each Evaluate or export captures one UTC instant for that run and records it in results and downloads. Leave the checkbox off to use the current UTC time. Check it and set the field to replay a prior run with a real UTC timestamp (YYYY-MM-DDTHH:MM:SSZ). Impossible dates are rejected.
