# v2.3.0 Release Gate Record

This durable record defines the evidence required to seal v2.3.0. It is not a live publication-status page. Actual publication status is determined only by the repository's v2.3.0 GitHub tag/release and the final release seal recorded through the protected release process.

- Version identity is `2.3.0` in package metadata, public release line, changelog, and release notes.
- Every protected Contract v1 and primary runtime file listed in the v2.3.0 mission is byte-unchanged.
- The common profile-result contract, registry, CLI exit behavior, deterministic serialization, and `authority_effect: NONE` validate.
- Auditable AI PASS/FAIL and hard-failure classes, including bounded positive advancement, pass repository-native tests.
- The seeded synthetic magnetic-navigation exercise reproduces exactly and prohibited quantum/operational claims fail closed.
- CISO accountability, stop-condition, evidence, explicit-time expiry, and `NOT_YET_ESTABLISHED` dependency boundaries pass.
- Decision Pack manifest digest checking, non-authorizing handoff evidence references, and browser rendering of the common contract pass.
- Existing tests, repository validation, generated-artifact drift checks, and `git diff --check` are green without new dependencies or generated cache files.
- Protected review, hosted CI, current-main verification, final seal, tag, and release publication are recorded by the release process.

## Public boundary
