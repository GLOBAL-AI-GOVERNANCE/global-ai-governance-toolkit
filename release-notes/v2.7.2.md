# v2.7.2 — Resolvable Schema Identifiers

Global AI Governance Toolkit v2.7.2 gives every published schema an identifier that resolves to the schema itself, so people and tools can trust what a contract refers to.

## What changes

- Every absolute schema `$id` uses the release-pinned form `https://raw.githubusercontent.com/GLOBAL-AI-GOVERNANCE/global-ai-governance-toolkit/v2.7.2/<path>` and returns the exact document shipped in this release. Earlier identifiers named `github.com` paths that did not resolve. Consumers that match on the old identifier strings should update them.
- CI checks that each absolute `$id` names the file's own path at a released tag. The Release Assets workflow fetches every `$id` from the tag and requires the identical document before it attaches assets.
- The distribution is named `global-ai-governance`, so the wheel and sdist are `global_ai_governance-2.7.2-py3-none-any.whl` and `global_ai_governance-2.7.2.tar.gz`. The command `gaig` and the import package `gaig_toolkit` are unchanged.
- The wheel installs only `gaig_toolkit` at the top level; the reference tooling ships under `gaig_toolkit/_bundled/automation`. Repository scripts, CI paths, and the GitHub Action are unchanged.
- Package metadata gains an SPDX license, classifiers, and project links. README links are absolute and pinned to the release tag.
- The site root at ai-governance.solutions is the Global AI Governance landing page, followed by the unchanged browser Toolkit at `#toolkit`. The Connect page and `llms.txt` add Claude Code and Grok CLI setup and an Action Level guard section.

## What stays the same

- Schema content, required fields, types, and validation results. Only `$id` values differ. Status: TESTED (unit tests, browser parity, Decision Pack reproducibility, and hosted CI).
- Exit codes, flags, structured errors, JSON outputs, findings, and check logic.
- The package is not on PyPI. The PyPI and TestPyPI publishing jobs remain inactive.
- No capability, authority, certification, or external reproducibility claim is strengthened.
- `authority_effect` remains NONE.

## Release assets

Built from the tag by the Release Assets workflow: wheel, sdist, a CycloneDX SBOM of the clean wheel install (`*.cdx.json`), and `SHA256SUMS`, with a GitHub build-provenance attestation for every asset listed in `SHA256SUMS`. Check a file with `sha256sum -c SHA256SUMS` or `gh attestation verify <file> --repo GLOBAL-AI-GOVERNANCE/global-ai-governance-toolkit`.
