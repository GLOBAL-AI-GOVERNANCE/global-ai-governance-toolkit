# v2.7.0 — `gaig` Only

Global AI Governance Toolkit v2.7.0 removes the deprecated `gag` names. `gaig` is the only command.

## What changes

- **Breaking:** the `gag` command is no longer installed. Run `gaig` (`gaig check`, `gaig normalize`, `gaig profile`, `gaig verify`).
- **Breaking:** the `gag_toolkit` import package is removed. Import `gaig_toolkit`.
- **Breaking:** the GitHub Action no longer exports `GAG_CHECK_REPORT_DIR`, `GAG_CHECK_EXIT_CODE`, or `GAG_CHECK_GATE_STATE`. Use `GAIG_CHECK_*` or the step outputs `report-dir`, `exit-code`, and `gate-state`.
- Checks, schemas, contracts, findings, and Decision Pack output are unchanged. Status: TESTED (hosted CI and a fresh-clone Quick Start).
- Release assets: wheel, sdist, and `SHA256SUMS`, built from the tag by the Release Assets workflow.
- Earlier releases are unchanged and still install the names they shipped with.
- No capability, authority, certification, or external reproducibility claim is strengthened.
- `authority_effect` remains NONE.
