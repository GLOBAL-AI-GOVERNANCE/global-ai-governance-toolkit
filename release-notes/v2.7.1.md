# v2.7.1 — Plain Run Output

Global AI Governance Toolkit v2.7.1 makes `gaig` output easier to act on. It changes no behavior that scripts or agents depend on.

## What changes

- Success output reads "Output contracts and Decision Pack integrity verified." in place of an internal phase name.
- A blocked `gaig check` run keeps its first line, then prints where the reports were written, the top three blocking findings to fix, and that `--fail-on none` generates the Decision Pack for review without failing.
- The browser check labels risk tiers as coming from the built-in calculator.
- Three profile schemas gain an `$id` like the other schemas. Required fields, types, and validation results are unchanged.
- The completed rename migration note is removed. The changelog and earlier release notes remain the record.

## What stays the same

- Exit codes (`0` pass, `1` blocked, `2` input or configuration error), flags, structured errors, JSON outputs, schemas, contracts, findings, and check logic. Status: TESTED (unit tests that assert the exit codes, the unchanged first blocked line, and the output contracts; hosted CI).
- Earlier releases are unchanged.
- No capability, authority, certification, or external reproducibility claim is strengthened.
- `authority_effect` remains NONE.

## Release assets

Built from the tag by the Release Assets workflow: wheel, sdist, a CycloneDX SBOM of the clean wheel install (`*.cdx.json`), and `SHA256SUMS`, with a GitHub build-provenance attestation for every asset listed in `SHA256SUMS`. Check a file with `sha256sum -c SHA256SUMS` or `gh attestation verify <file> --repo GLOBAL-AI-GOVERNANCE/global-ai-governance-toolkit`.
