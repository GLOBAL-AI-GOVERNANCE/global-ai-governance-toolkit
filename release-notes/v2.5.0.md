# v2.5.0 candidate — Organizational AI Maturity Evidence

This note prepares a later tag. It is not a GitHub Release. The published release remains v2.4.0 until v2.5.0 is tagged.

## What the candidate contains

- An organizational AI maturity evidence profile. A human determines the maturity level. The evaluator checks whether submitted evidence can carry that determination.
- Four source level labels only: Basic, Ready, Dynamic, and Advanced. No numerical score.
- Partial and full-framework coverage. Partial coverage is not framework completion.
- A local-only browser for assessment, review, and export of `profile-result.json`.
- Machine-interface version 1.2.0. `authority_effect` remains NONE.

## Boundaries

- No certification, compliance determination, deployment authorization, or authority transfer.
- No independent machine declaration of organizational maturity.
- Framework attribution stays with the isolated adapter. Use does not imply publisher endorsement.
