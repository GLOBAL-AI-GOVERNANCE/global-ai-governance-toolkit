# v2.2.0 - AI Sovereignty Control Layer

Global AI Governance Toolkit v2.2.0 advances the working public reference line with two bounded increments: the local-first browser and machine-interface improvements accumulated on `main` after v2.1.0, and an additive AI sovereignty assessment path.

## What Changed

- The local-first browser, contract-generated inventory template, machine interface, and first-time-use improvements are now part of the tagged release line.
- The AI Sovereignty Control Layer adds declared-control assessment for data retention and training use, model liquidity, compute assurance, permissions, auditability, rollback, human oversight, shutdown, and owned context.
- A dedicated sovereignty workflow proves a passing reference case and a deliberately blocked enforcement case without changing the primary Decision Pack runtime.

## Verification

The release gate validates the existing repository and Decision Pack suite, the sovereignty package manifest, a passing sovereignty baseline, an intentionally blocked sovereignty demo, pinned GitHub Actions, local Markdown links, and repository integrity.

## Evidence Boundary

This is a working public reference toolkit. The sovereignty assessment evaluates submitted declarations and checked-in control logic. It does not attest provider behavior, certify compliance, establish legal or regulatory conclusions, approve deployment, accept risk, or establish production authorization.

Humans remain responsible for final review, interpretation, risk acceptance, deployment decisions, restrictions, rollback, suspension, and shutdown.
