# v2.8.0 — Autonomous Agent Shutdown Evidence

Global AI Governance Toolkit v2.8.0 makes the independent assurance profile require an agent passport reference and a recent, passing shutdown test before an autonomous agent's case can pass.

## What changes

- Independent assurance contract 0.2.0 (profile id `independent-assurance-v0.1` unchanged). With `autonomous_agent: true`, a case needs `agent_passport_ref` (`passport_id`, `sha256:` `passport_digest`) and `shutdown_evidence` with `shutdown_tested_at`, `result: PASSED`, and at least one evidence reference.
- The shutdown test must be no more than 90 days old at the evaluation time. `max_shutdown_test_age_days` can shorten that bound, never extend it. A test dated after the evaluation time, or a run without an evaluation time, fails closed.
- New CRITICAL rule IDs: `AGENT_PASSPORT_MISSING`, `SHUTDOWN_TEST_MISSING`, `SHUTDOWN_TEST_NOT_PASSED`, `SHUTDOWN_TEST_EVIDENCE_REFS`, `SHUTDOWN_TEST_STALE`, `SHUTDOWN_TEST_IN_FUTURE`, `SHUTDOWN_TEST_AGE_UNKNOWN`. Results report `details.shutdown_test` with the state, age, and bound.
- The shutdown hint names the required fields and states that the profile checks the submitted record. It no longer asks for "verified" evidence.
- Six synthetic fixtures and tests cover pass, missing passport, missing, stale, failed, and tighter-bound shutdown tests.

## What stays the same

- Existing fixtures and their results, the high-consequence check (now also satisfied by current structured evidence), exit codes, flags, and every other profile and contract.
- The profile checks submitted records. It does not establish that a shutdown test occurred or validate the passport itself. Status: TESTED (unit tests and hosted CI).
- The package is not on PyPI. No capability, authority, certification, or external reproducibility claim is strengthened. `authority_effect` remains NONE.
