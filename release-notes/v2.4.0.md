# v2.4.0 — Assurance Interoperability & Agent Connectivity

Global AI Governance Toolkit v2.4.0 publishes the assurance and agent-connectivity increment already on this line.

## Shipped

- Independent Assurance, Mission Assurance, and Machine Learning Assurance profiles for CLI use, in addition to the Auditable AI, synthetic Quantum-AI, and CISO accountability profiles from v2.3.0.
- Browser rendering remains limited to Auditable AI, the synthetic Quantum-AI exercise, and CISO accountability.
- Machine-interface discovery separates `cli_supported` from `browser_supported`. `supported` stays equal to the browser list. Interface version 1.1.0. `authority_effect` remains NONE.
- Native reference interoperability, local Assurance Context Binding consumption, and Decision Pack / Context Binding consistency. No external retrieval and no authority transfer.
- Mission-assurance challenge and an unregistered offline synthetic agent-action evidence example.
- Browser input invalidation, accessibility improvements, and a synthetic example with governance gaps.
- `llms.txt` and a Connect page for local agent setup. Remote MCP use requires allowed hosts and a bearer token. No hosted endpoint is operated.
- History privacy checks and pull-request identity controls.

## Boundaries

- `authority_effect` remains NONE.
- No certification, compliance determination, deployment authorization, or authority transfer.
- No organizational AI maturity profile and no maturity browser route.
- Remote connector recipes are not a claim of live provider validation.

## Not in this release

- No organizational AI maturity profile.
- No maturity browser route.
