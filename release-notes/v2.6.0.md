# v2.6.0 — Primary Command `gaig`

Global AI Governance Toolkit v2.6.0 makes `gaig` the primary command.

## What changes

- The installed command is `gaig` (`gaig check`, `gaig normalize`, `gaig profile`, `gaig verify`).
- `gag` remains installed as a deprecated alias of the same command. Existing scripts keep working with unchanged output.
- The import package is `gaig_toolkit`. `gag_toolkit` remains as a deprecated alias package.
- The composite GitHub Action runs `gaig check` and exports `GAIG_CHECK_REPORT_DIR`, `GAIG_CHECK_EXIT_CODE`, and `GAIG_CHECK_GATE_STATE`. The deprecated `GAG_CHECK_*` names are exported with the same values.
- Release assets: wheel, sdist, and `SHA256SUMS`, built from the tag by the Release Assets workflow.
- No capability, authority, certification, or external reproducibility claim is strengthened.
- `authority_effect` remains NONE.
